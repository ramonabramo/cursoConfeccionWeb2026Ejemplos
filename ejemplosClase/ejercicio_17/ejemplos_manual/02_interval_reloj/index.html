⏱️ Ejemplo de Referencia 02

Metrónomo / Reloj Repetitivo

Uso de setInterval() para repetir una acción periódica y clearInterval() para frenarla automáticamente tras N vueltas.

VUELTAS (Máx. 5) 0
1 2 3 4 5

Reloj detenido. Pulsa «Iniciar metrónomo».

🍳 Analogía de pizarra: Funciona igual que un metrónomo musical: emite un pulso regular cada 1000 ms. Si no le indicamos una condición de parada (vueltas === 5) o pulsamos el botón de detener, continuará funcionando indefinidamente.
