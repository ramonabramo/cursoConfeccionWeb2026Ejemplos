Consumo de Servidor con fetch()

Conectamos nuestra aplicación con una base de datos real o simulada mediante peticiones asíncronas HTTP.

🌐 Concepto didáctico: 1. Usamos fetch() con async / await para comunicarnos con el backend.
2. El servidor responde con un JSON de la base de datos.
3. Convertimos cada registro en una instancia de la class Alumno (Rehidratación).
4. Combinamos los datos remotos con la persistencia local de localStorage.
