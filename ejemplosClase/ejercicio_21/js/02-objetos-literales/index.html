Gestión con Objetos Literales

Agrupamos los datos en una sola entidad: { nombre: "...", nota: 8.5 }.

💡 Concepto didáctico: Avanzamos hacia la cohesión de datos. Cada alumno es un objeto literal. El array contiene objetos: alumnos = [{ nombre: 'Lucía', nota: 8.5 }]. En localStorage se guarda en una sola clave. Si eliminamos o reordenamos el array, el nombre y la nota siempre permanecen unidos de forma indivisible.
