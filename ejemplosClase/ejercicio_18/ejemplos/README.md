## 🚀 Cómo Ejecutar los Ejemplos

1. Abre cualquiera de las subcarpetas directamente en el navegador haciendo doble clic en su archivo `index.html`.
2. Para una experiencia guiada completa con navegación unificada, abre el portal principal en [`../index.html`](file:///d:/Ramon/www/confeccion2026/ejemplos/iniciales/ejercicio_18/index.html).
3. Abre las herramientas para desarrolladores (**F12** en Windows) y observa la pestaña **Console**, donde cada ejemplo imprime explicaciones pedagógicas detalladas de cada operación.
