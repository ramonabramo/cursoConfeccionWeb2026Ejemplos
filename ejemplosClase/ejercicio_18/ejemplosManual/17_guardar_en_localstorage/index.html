Ejemplo 17: Persistencia de Objetos en LocalStorage

Almacenamiento persistente en el navegador: transformar objetos en JSON antes de guardar y deserializarlos al recuperar.

guardar-en-localstorage.js
JavaScript
const alumno = { nombre: "Ana", edad: 22 };

// Guardar: localStorage solo admite texto
localStorage.setItem("alumno", JSON.stringify(alumno));

// Recuperar: texto -> objeto
const recuperado = JSON.parse(localStorage.getItem("alumno"));
console.log(recuperado.nombre);
