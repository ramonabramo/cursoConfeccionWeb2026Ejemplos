Ejemplo 01: Crear Objetos (Tres Formas)

Tres formas habituales de crear objetos: directa, objeto vacío con asignación posterior y sintaxis abreviada ES6 a partir de variables existentes.

crear-objetos.js
JavaScript
// Forma 1: creación directa con sus propiedades (la más habitual)
const alumno = {
  nombre: "Elena",
  edad: 20,
  matriculado: true
};

// Forma 2: objeto vacío y asignación posterior
const ficha = {};
ficha.curso = "JavaScript Básico";
ficha.aula = 104;

// Forma 3: abreviada, a partir de variables existentes (ES6)
const marca = "Logitech";
const modelo = "MX Master";
const raton = { marca, modelo }; // equivale a { marca: marca, modelo: modelo }

console.log(alumno);
console.log(ficha);
console.log(raton);
