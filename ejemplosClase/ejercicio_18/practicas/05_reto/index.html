🔐 Cuenta Bancaria con Saldo Privado

Aprende a proteger datos mediante una clausura (función autoejecutable IIFE) de forma que cuenta.saldo devuelva undefined.

📋 Requisitos del Reto

  • titular: Propiedad pública con valor "Lucía Navarro".
  • ingresar(importe): Suma al saldo privado y devuelve "Saldo: 300€" (rechaza importes ≤ 0).
  • retirar(importe): Resta del saldo y devuelve "Saldo: 200€" (devuelve "Operación denegada" si es ≤ 0 o supera el saldo).
  • consultarSaldo(): Devuelve el número del saldo actual.
  • historial(): Devuelve un array con el registro textual de cada movimiento.
  • Seguridad: cuenta.saldo debe ser undefined.
