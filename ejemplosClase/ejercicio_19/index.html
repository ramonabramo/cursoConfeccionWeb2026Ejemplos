📦 Ejercicio 19: Iniciación a Objetos Literales en JavaScript

Aprende paso a paso los fundamentos de los objetos en JavaScript sin complicaciones: de variables sueltas a estructuras organizadas con { clave: valor }, lectura por punto y corchetes, métodos sencillos con this, listas de objetos y conexión directa con el DOM.

Profesor: Ramón Abramo · Santander (Cantabria) · Curso 2026
FUNDAMENTOS

🏷️ Objeto Literal { }

Agrupa pares clave: valor para reunir toda la información de una entidad (un alumno, un producto, un usuario) en una sola variable.

📁 Analogía: Una ficha de cartulina con campos etiquetados.
ACCESO Y CONTROL

🔍 Punto y Corchetes

Accede con objeto.propiedad de forma limpia o con objeto['propiedad'] cuando la clave viene de una variable.

🗝️ Analogía: La llave exacta para abrir cada cajón del mueble.
ACCIONES

⚙️ Métodos y 'this'

Añade funciones dentro del objeto que interactúan con sus propios datos utilizando la palabra clave this ("este mismo objeto").

🕹️ Analogía: El acelerador de un coche que incrementa su propia velocidad.
COLECCIONES

📋 Arrays de Objetos

Combina listas y objetos para representar catálogos reales en la web y recórrelos de forma intuitiva con bucles for...of.

📚 Analogía: Una estantería donde cada libro es un objeto con título y precio.
