Ejemplo 02: Tipos de Valores en Propiedades

El valor de una propiedad puede ser cualquier tipo: texto, número, booleano, null, array, objeto o función (método).

tipos-de-valores.js
JavaScript
const demo = {
  texto: "Hola",
  numero: 42,
  booleano: true,
  nada: null,
  lista: [1, 2, 3],
  anidado: { clave: "valor" },
  accion() { return "Soy un método"; }
};

console.log(typeof demo.texto);
console.log(typeof demo.lista);
console.log(typeof demo.accion);
console.log(demo.accion());
