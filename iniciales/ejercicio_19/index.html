📦 Ejercicio 18: Objetos Literales en JavaScript

Aprende a estructurar entidades coherentes con notación literal { clave: valor }, métodos con this, estructuras complejas anidadas, colecciones y serialización con formato JSON.

Profesor: Ramón Abramo · Más de 25 años de experiencia docente
SINTAXIS DIRECTA

🏷️ Objeto Literal { }

Agrupa pares clave: valor para representar una entidad autónoma sin necesidad de clases.

📁 Analogía: Una ficha de expediente con casillas etiquetadas.
COMPORTAMIENTO

💳 Métodos y 'this'

Funciones que viven dentro del objeto y acceden a su estado interno mediante la palabra reservada this.

🕹️ Analogía: Los botones de un reproductor que operan sobre su propia cinta.
COLECCIONES

🛍️ Arrays de Objetos

El estándar web para listas y catálogos, sustituyendo al antipatrón de arrays paralelos desincronizados.

📚 Analogía: Una estantería de libros donde cada tomo tiene título y precio.
INTERCAMBIO

🌐 Formato JSON

Serialización con JSON.stringify() y reconstrucción con JSON.parse() para servidores y localStorage.

📦 Analogía: Empaquetar un mueble en una caja de cartón para enviarlo.
