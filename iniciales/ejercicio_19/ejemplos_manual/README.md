# 📚 Ejemplos del Manual de Referencia · Ejercicio 18

En este directorio se encuentran las **6 demostraciones prácticas interactivas** correspondientes a cada una de las secciones del **Manual de Referencia Rápida sobre Objetos Literales en JavaScript**.

Cada ejemplo es una aplicación web independiente con su propio `index.html`, `style.css` y `app.js` comentado pedagógicamente.

---

## 🗂️ Índice de Ejemplos

| Carpeta | Título y Enfoque Didáctico | Conceptos JavaScript Clave |
| :--- | :--- | :--- |
| **[`01_producto_basico/`](01_producto_basico/)** | 🏷️ **Objeto Producto Básico** | Sintaxis literal `{}`, pares `clave: valor`, notación punto y corchetes, adición dinámica y borrado con `delete`. |
| **[`02_cuenta_bancaria/`](02_cuenta_bancaria/)** | 💳 **Cajero y Cuenta Bancaria** | Métodos abreviados en objetos, palabra reservada `this`, modificación de propiedades internas y validación de negocio. |
| **[`03_estudiante_anidado/`](03_estudiante_anidado/)** | 🎓 **Expediente del Estudiante** | Objetos anidados (`estudiante.direccion.ciudad`), arrays dentro de objetos y métodos que calculan la media sobre listas propias. |
| **[`04_catalogo_arrays/`](04_catalogo_arrays/)** | 🛍️ **Catálogo de Tienda (Colecciones)** | Arrays de objetos literales, bucles `for...of`, filtrado dinámico por disponibilidad y ordenación por precio. |
| **[`05_claves_y_json/`](05_claves_y_json/)** | 🔤 **Inspección de Claves y JSON** | Métodos globales `Object.keys()`, `Object.values()`, serialización con `JSON.stringify()`, `JSON.parse()` y persistencia en `localStorage`. |
| **[`06_privacidad_modulo/`](06_privacidad_modulo/)** | 🔐 **Privacidad y Patrón Módulo** | Miembros públicos por defecto, convención `_` vs Privacidad REAL mediante clausuras e IIFE (Immediately Invoked Function Expression). |

---

## 🚀 Cómo ejecutar los ejemplos

Puedes abrir cualquiera de los archivos `index.html` directamente en tu navegador habitual o utilizar la extensión **Live Server** de VS Code para experimentar en tiempo real con las modificaciones en el código fuente.
