# 📚 Ejemplos del Manual de Referencia · Ejercicio 19

**Curso:** Confección y Publicación de Páginas Web (IFCD0110)  
**Profesor:** Ramón Abramo · Santander (Cantabria)  
**Nivel:** Iniciación Práctica a Objetos Literales en JavaScript

En este directorio se encuentran las **6 demostraciones prácticas interactivas** correspondientes a cada una de las secciones del **Manual de Referencia Rápida sobre Objetos Literales en JavaScript (Nivel Básico)**.

Cada ejemplo es una aplicación web independiente con su propio `index.html`, `style.css` y `app.js` comentado pedagógicamente.
