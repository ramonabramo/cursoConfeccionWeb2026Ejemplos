Ejemplo 06 · Privacidad y Clausuras

🔐 Privacidad en Notación Literal y Patrón Módulo

Compara la convención visual con guion bajo (_pin) frente a la privacidad REAL que ofrecen las clausuras mediante una IIFE.

⚠️ CASO A: Convención _ (Falsa Privacidad)

Objeto Literal Directo

Las propiedades con _ son solo una advertencia para otros desarrolladores. Cualquier script puede leerlas o alterarlas directamente.

Titular: Marta

PIN Secreto: 1234

Saldo Interno: 500 €

🛡️ CASO B: Clausura (Privacidad Real)

Caja Fuerte con Patrón Módulo

Las variables let _pin y let _dinero viven dentro de la IIFE. Desde el exterior devuelven undefined. Solo se accede con el método público.

cajaFuerte._dinero: undefined

cajaFuerte._pinSecreto: undefined

📋 Resumen de Reglas de Privacidad en JavaScript

Técnica ¿Es realmente privado? ¿Cómo se declara? Ámbito de uso
Convención _variable ❌ No (accesible públicamente) { _secreto: "123" } Objetos literales directos
Clausura / IIFE (Módulo) ✔ Sí (100% privado en memoria) (() => { let _sec; return { ... }; })() Objetos con seguridad real
Campos con almohadilla #privado ✔ Sí (nativo de ES2022) class Cuenta { #saldo; } Solo dentro de class, nunca en objetos literales
