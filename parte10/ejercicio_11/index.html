Ejercicio 11 - Herencia y Polimorfismo (extends, super y Method Overriding)

Conecta clases padre e hijo con extends, domina la llamada obligatoria a super() antes de usar this y sobrescribe métodos para lograr polimorfismo.

Ejemplo Teórico Guiado
class Empleado { constructor(nombre, sueldo) { this.nombre = nombre; this.sueldo = sueldo; } trabajar() { return `${this.nombre} realiza tareas generales.`; } } class Desarrollador extends Empleado { constructor(nombre, sueldo, lenguaje) { super(nombre, sueldo); // ⚠️ OBLIGATORIO antes de 'this' this.lenguaje = lenguaje; } trabajar() { // Method Overriding return `${super.trabajar()} Específicamente programa en ${this.lenguaje}.`; } }

Compara la clase base Empleado con la clase hija Desarrollador. Observa la invocación obligatoria a super() en el constructor y la sobrescritura de métodos (Method Overriding).
