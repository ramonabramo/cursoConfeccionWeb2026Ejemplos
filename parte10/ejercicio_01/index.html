Ejercicio 01 - Objetos Literales, Propiedades y Métodos (this)

Aprende a estructurar datos asociativos clave-valor mediante sintaxis literal, accediendo con notación de punto y corchetes, e invocando métodos de instancia mediante this.

Ejemplo Teórico Guiado
// Objeto literal con propiedades y método const usuario = { nombre: 'Carlos Ruiz', rol: 'Frontend Dev', activo: true, saludar() { return `Hola, soy ${this.nombre} y trabajo como ${this.rol}.`; } }; // Notación de punto vs notación de corchetes console.log(usuario.nombre); // 'Carlos Ruiz' console.log(usuario['rol']); // 'Frontend Dev'

Modifica las propiedades del objeto literal usuario desde los controles. Observa cómo el método interno obtenerFichaTecnica() accede a sus datos usando this.
