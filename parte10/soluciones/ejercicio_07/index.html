Ejercicio 07 - Clases en ES6 (Constructor, Operador new e Instancias)

Aprende a definir una clase formal con la palabra reservada class, inicializar propiedades en el constructor() mediante this y crear instancias independientes con new.

Ejemplo Teórico Guiado
// Definición formal de Clase (Syntactic Sugar de prototipos) class Coche { constructor(marca, modelo, velocidadMax) { this.marca = marca; this.modelo = modelo; this.velocidadMax = velocidadMax; this.velocidadActual = 0; } acelerar(km = 10) { this.velocidadActual = Math.min(this.velocidadActual + km, this.velocidadMax); } } // Instanciación con 'new' const coche1 = new Coche('Seat', 'Ibiza', 180); const coche2 = new Coche('Tesla', 'Model 3', 225);

Dos instancias creadas a partir de la misma plantilla class Coche. Cada objeto mantiene su propio estado de velocidad sin afectar al otro.
