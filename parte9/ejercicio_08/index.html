Ejercicio 08 - Simulador de Carga de Batería Inteligente (Colores e Intervalos)

Diseña un simulador interactivo de batería que aumente su carga periódicamente y varíe de color dinámicamente según el nivel alcanzado.

Práctica para el Alumno
// Reto para el alumno: // 1. Cada 80ms incrementar bateria en 1%. // 2. Si bateria < 20% -> color rojo (#ef4444) // 3. Si bateria < 80% -> color naranja (#f59e0b) // 4. Si bateria >= 80% -> color verde (#10b981) // 5. Al llegar a 100%, detener con clearInterval().

Conecta el cargador para iniciar la recarga. La batería cambiará de color dinámicamente (rojo <20%, naranja <80%, verde ≥80%) y se detendrá al 100%.
