Ejercicio 07 - Barra de Progreso y Porcentaje de Carga (Animación con setInterval)

Aprende a modificar dinámicamente propiedades CSS (style.width) con setInterval() para crear animaciones fluidas de carga con autolimpieza al 100%.

Ejemplo Teórico Guiado
// Incrementar el ancho de la barra CSS cada 40ms intervaloId = setInterval(() => { progreso++; barra.style.width = progreso + '%'; texto.textContent = progreso + '%'; if (progreso >= 100) { clearInterval(intervaloId); // Autolimpieza } }, 40);
