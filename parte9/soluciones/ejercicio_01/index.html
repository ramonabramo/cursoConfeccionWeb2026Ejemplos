Ejercicio 01 - Notificación Toast Temporal con Opción de Deshacer (clearTimeout)

Aprende a diferir la ejecución de una acción con setTimeout() y a cancelarla a tiempo con clearTimeout() antes de que se cumpla el plazo programado.

Ejemplo Teórico Guiado
// 1. Programar la ejecución futura (4 segundos = 4000ms) const timeoutId = setTimeout(() => { confirmarEliminacionDefinitiva(); }, 4000); // 2. Cancelar la ejecución si el usuario pulsa "Deshacer" clearTimeout(timeoutId);

Haz clic en Eliminar Elemento. Tendrás 4 segundos para pulsar Deshacer Eliminación antes de que la acción sea irreversible.
