Ejercicio 09 - Carrusel de Testimonios con Rotación Automática y Pausa al Hover

Implementa el patrón rey de la web moderna: autoplay con setInterval(), pausa con mouseenter (clearInterval) y reanudación con mouseleave.

Ejemplo Teórico Guiado
// Patrón universal de carruseles interactivos: carrusel.addEventListener('mouseenter', () => { clearInterval(intervaloId); // Pausa al pasar el ratón }); carrusel.addEventListener('mouseleave', () => { iniciarAutoPlay(); // Reanuda al retirar el ratón });

Este carrusel rota automáticamente cada 3 segundos. Pasa el ratón por encima del marco para pausar la rotación y retíralo para que continúe.
