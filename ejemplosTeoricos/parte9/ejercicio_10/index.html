Ejercicio 10 - Teletipo de Noticias de Última Hora en Vivo (Ticker con Pausa al Hover)

Crea una barra de noticias rotativas en vivo que cambie de titular cada 2.5 segundos y se detenga automáticamente al posar el ratón encima.

// Reto para el alumno: // 1. Array de noticias con titular, categoría y hora. // 2. setInterval cada 2500ms para rotar noticias. // 3. mouseenter -> pausar con clearInterval. // 4. mouseleave -> reanudar con nuevo setInterval.
