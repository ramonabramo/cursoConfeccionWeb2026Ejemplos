Ejercicio 05 - Reloj Digital en Vivo con Fecha y Segundero (setInterval + Date)

Aprende a consultar la hora del sistema con new Date() en tiempo real cada 1000ms mediante setInterval(), formateando con padStart(2, "0").

Ejemplo Teórico Guiado
// Leer y formatear la hora cada 1000ms setInterval(() => { const ahora = new Date(); const hh = String(ahora.getHours()).padStart(2, '0'); const mm = String(ahora.getMinutes()).padStart(2, '0'); const ss = String(ahora.getSeconds()).padStart(2, '0'); display.textContent = `${hh}:${mm}:${ss}`; }, 1000);
