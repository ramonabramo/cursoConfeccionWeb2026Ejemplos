Solución Ejercicio 02 - Recorrido masivo con forEach() para modificar clases y estilos

Aprende a recorrer todos los nodos de una NodeList con forEach() para aplicar o eliminar clases CSS masivamente sobre múltiples elementos del DOM.

Artículo 1: ¿Qué es el DOM?

El Document Object Model es la representación en memoria del árbol HTML creado por el navegador.

Artículo 2: ¿Qué es una NodeList?

Es una colección ordenada de nodos devuelta por querySelectorAll() con soporte nativo de forEach().

Artículo 3: JavaScript Moderno

Las buenas prácticas actuales recomiendan usar forEach() en lugar de bucles manuales para recorrer nodos.

Artículo 4: Manipulación de Clases

El objeto classList permite añadir, quitar o alternar clases CSS sin sobreescribir las existentes.
