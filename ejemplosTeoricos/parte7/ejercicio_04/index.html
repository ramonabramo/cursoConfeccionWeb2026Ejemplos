Ejercicio 04 - Bucle while con búsqueda y parada anticipada (break)

Aplica el bucle while para buscar un elemento en un array y detener la ejecución inmediatamente con break en cuanto se encuentre la coincidencia.

Práctica del Alumno
Inventario: ['Teclado', 'Ratón', 'Monitor', 'Altavoz', 'Impresora', 'Webcam']
Selecciona una acción para ver el resultado...
