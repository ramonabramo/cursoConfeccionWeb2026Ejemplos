Ejercicio 09 - Encapsulamiento con Campos Privados (#) y Getters / Setters

Domina la privacidad nativa en tiempo de ejecución de ES6+ mediante el prefijo de almohadilla (#), la validación con getters y setters y el error de acceso externo.

Ejemplo Teórico Guiado
class CuentaBancaria { #saldo; // Campo privado real en tiempo de ejecución #pin; constructor(titular, saldoInicial = 0, pin = '1234') { this.titular = titular; this.#saldo = saldoInicial; this.#pin = pin; } get saldo() { return this.#saldo; } // Getter de lectura set pin(nuevoPin) { // Setter con validación if (/^\d{4}$/.test(nuevoPin)) this.#pin = nuevoPin; } }

Prueba la privacidad real de #saldo. Intentar acceder directamente a cuenta.#saldo fuera de la clase produce un SyntaxError en tiempo de ejecución.
