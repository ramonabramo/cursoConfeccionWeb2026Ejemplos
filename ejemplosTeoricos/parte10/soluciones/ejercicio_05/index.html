Ejercicio 05 - Objetos JS vs Formato JSON (JSON.stringify y JSON.parse)

Comprende qué es el formato JSON, sus diferencias con los objetos de JavaScript (desaparición de métodos, comillas dobles obligatorias) y su conversión con JSON.stringify() y JSON.parse().

Ejemplo Teórico Guiado
// Objeto nativo de JavaScript (admite métodos) const dev = { nombre: 'Ana', saludar() { return 'Hola'; } }; // 1. Serializar a texto JSON (¡el método saludar desaparece!) const jsonString = JSON.stringify(dev, null, 2); // 2. Deserializar de texto JSON a objeto JS const objetoReconstruido = JSON.parse(jsonString);

Experimenta con la serialización (Objeto a JSON) y deserialización (JSON a Objeto). Observa cómo las funciones y métodos no existen en JSON y cómo las claves exigen obligatoriamente comillas dobles "clave".
